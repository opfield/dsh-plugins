# Opfield для DeepSeek Harness

[English](README.md)

Плагин `@opfield/dsh-opfield` подключает Opfield к DeepSeek Harness (DSH). Для каждого инстанса Opfield нужны только адрес и вход: ключи вручную вводить не нужно.

- **Инстансы.** Сколько угодно установок Opfield. Каждая подключается к модели как MCP-сервер через MCP Hub, всегда компактным каталогом (lazy): у Opfield сотни инструментов.
- **Модели из одного инстанса.** Инстанс выбирается в выпадающем списке. Плагин сам выпускает inference-токен, направляет на инстанс маршрут моделей `opfield` и подтягивает список моделей с названиями, лимитами, поддержкой картинок и уровнями reasoning.
- **Компоненты** — отдельные строки в Plugins → Components, каждая со своим переключателем:
  - **Opfield budget** — остаток бюджета под композером;
  - **Prompt cache timer** — таймер prompt cache (5m или 1h);
  - **Compact offer** — предложение сделать `/compact`, когда кеш остыл.

Сборки не требует: это обычные JS-файлы.

## Установка

1. **Установи [MCP Hub](../mcp-hub)** (`@opfield/dsh-mcp-hub`). Через него идут вход и все запросы к Opfield.
2. **Plugins → Add plugin**: введи `@opfield/dsh-opfield`, затем **Enable now**. Перезапусти DSH.
3. **Plugins → Opfield → Add instance**: введи адрес, например `https://ops.example.com`, затем **Sign in**. Первый добавленный инстанс сразу выбирается источником моделей.

Через несколько секунд после входа в выборе модели появится Opfield, а под композером — остаток бюджета.

## Как это работает

- **Вход** — OAuth в MCP Hub. Токены хранятся в `<профиль>/mcp-hub/oauth/` с правами 0600 и обновляются сами.
- **Бюджет** читается инструментом `manage_inference_usage` через ту же MCP-сессию. REST-токен не нужен.
- **Inference-токен.** Если у маршрута нет ключа, плагин выпускает его инструментом `manage_inference_token` с именем «DeepSeek Harness · <хост>» и кладёт в хранилище ключей DSH под именем `OPFIELD_<ИМЯ>_INFERENCE_KEY`. Если у входа нет прав `feat:ai:use`, инстанс помечается «no inference access». Если Opfield отказал в выпуске, на странице появляется поле, куда можно вставить токен, выпущенный вручную.
- **Смена инстанса** переписывает у маршрута `opfield` адрес и ключ и заново синхронизирует модели. Если модели по умолчанию нет в новом инстансе, она меняется на первую доступную, и на странице об этом есть строка. В уже открытых чатах модель остаётся прежней, пока её не сменить.
- **Удаление инстанса** отзывает токен, который выпустил плагин, и удаляет ключ из хранилища. Токены, выпущенные вручную, плагин не трогает.
- **MCP выключен** у инстанса — модель не видит его инструментов, но сессия продолжает работать для бюджета и токенов, если инстанс выбран источником моделей.

В MCP Hub такие серверы показаны с пометкой «Opfield». Менять и удалять их можно только здесь.

## Настройки

Всё на странице **Plugins → Opfield**, применяется сразу:

- **Instances** — карточка в одну строку: статус, Sign in, переключатель MCP. Стрелка раскрывает перезапуск, остановку, обновление инструментов, выход, правку адреса и удаление.
- **Models** — источник моделей (или «None»); под ним число моделей, время синхронизации, остаток бюджета и Refresh.
- **Components** — настройки включённых компонентов: срок prompt cache (5m / 1h) у таймера и порог `/compact`. Сами компоненты включаются в Plugins → Components.
- **Advanced** (свёрнуто) — пороги цвета и частота обновления бюджета, срок кеша произвольным числом, интервал синхронизации и маски моделей, имя маршрута и записи `llm-pi-ai`, таймауты.

Это запись `opfield-usage` в `cordis.patch.yml` профиля:

```yaml
- id: opfield-usage
  name: '@opfield/dsh-opfield'
  config:
    instances:
      - { name: opfield, url: https://ops.example.com, mcp: true }
    inference: opfield
    promptCacheTtlMinutes: 60
    compactMinTokens: 30000
```

Компоненты — записи `opfield-budget`, `opfield-cache-timer`, `opfield-compact-offer` того же пакета (`@opfield/dsh-opfield/budget` и т. д.); выключенная запись получает `disabled: true`.

Настройки версии 0.3 (`baseURL`, `display`, `modelSync`…) читаются как один инстанс `opfield`. Новый формат записывается при первом изменении на странице.
